### 1. Чем класс отличается от объекта?
Класс - это шаблон или чертеж, который описывает, какие данные и методы будут у сущности. Объект - это конкретный экземпляр этого класса, созданный в памяти через оператор new.

### 2. Для чего нужен конструктор и когда он вызывается?
Конструктор нужен для начальной настройки объекта, то есть для заполнения его свойств при создании. Он вызывается автоматически в тот момент, когда мы используем ключевое слово new.

### 4. Чем отличается $obj2 = $obj1 от $obj2 = clone $obj1?
При $obj2 = $obj1 обе переменные ссылаются на один и тот же объект в памяти, поэтому изменение одного затронет и другой. При clone создается абсолютно независимая копия объекта со своими собственными данными.

### 5. Чем статическое свойство отличается от обычного? Как к нему обратиться?
Обычное свойство свое у каждого объекта. Статическое свойство принадлежит всему классу и является общим для всех объектов. Обращаться к статическому свойству нужно через имя класса с двойным двоеточием.

### 6. Что такое readonly-свойство и когда его можно присвоить?
Это свойство, доступное только для чтения. Присвоить ему значение можно только один раз, обычно это делается внутри конструктора при создании объекта. После этого изменить его уже нельзя.

### 7. Что такое продвижение свойств в конструкторе?
Это возможность объявлять свойства прямо в параметрах конструктора, добавляя к ним модификаторы доступа. PHP автоматически создает эти свойства и заполняет их переданными значениями, избавляя от лишнего кода.

### 8. Как реализовать цепочку вызовов методов?
Для этого каждый метод в цепочке должен возвращать сам объект с помощью инструкции return $this. Также в сигнатуре метода нужно указывать тип возвращаемого значения static или self.

### 9. Назовите три магических метода и случаи, когда PHP их вызывает.
__construct - вызывается автоматически при создании объекта через new. __toString - вызывается, когда мы пытаемся вывести объект как строку. __get - вызывается при попытке прочитать несуществующее или недоступное свойство.

### 10. Чем protected отличается от private при наследовании?
protected свойства и методы доступны классам-наследникам, они могут их использовать. private доступны только внутри того класса, где они объявлены, классы-наследники их не видят.

### 11. Что делает ключевое слово final?
Оно запрещает изменение. Если пометить метод как final, его нельзя будет переопределить в дочерних классах. Если пометить класс, то от него нельзя будет наследоваться.

### 12. Как работает spl_autoload_register?
Он регистрирует функцию-загрузчик. Когда PHP встречает неизвестный класс, он автоматически вызывает эту функцию и передает ей имя класса. Функция должна найти нужный файл и подключить его.

### 13. Как стандарт PSR-4 связывает пространство имён и путь к файлу?
Он сопоставляет определенный префикс пространства имен с конкретной папкой в проекте. Благодаря этому правилу PHP точно знает, в каком файле искать класс, просто преобразуя его полное имя в путь.

### 14. Когда нужно выполнять composer dump-autoload?
Это нужно делать после изменения файла composer.json или при добавлении новых папок в структуру проекта, чтобы Composer перестроил карту автозагрузки классов.

### 3. Что означает $this и почему он недоступен в статических методах?
$this - это ссылка на текущий объект класса, позволяющая обращаться к его свойствам и методам. В статических методах он недоступен, потому что такие методы вызываются у самого класса, а не у объекта, и конкретного экземпляра в этот момент просто нет.
